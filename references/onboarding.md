# 先检查，再给当前需要的动作

先复用已有连接检查蝉妈妈、达人广场、浏览器组件和目标表读写权限。已就绪项不再要求操作。准备页自动更新，默认只展示五项状态、来源更新和微信采集进度；未满足项红字，提示“请按 Agent 引导操作”。不向商务解释内部实现或堆叠依据。

网站登录与控制连接独立：实测退出显示“未登录”；已登录但明确未授权显示“已登录 · Playwright 未授权”；连接失效显示在组件项“Playwright 未连接”。组件未安装显示“Playwright 未安装”。无法读取页面不推断退出或权限失效，也不覆盖有来源、时间的既有登录观察。用户明确报告登录/退出可记录为用户报告，随后核验；不可冒称自动验证。新页面证据替换旧观察。

# 登录时

仅列未登录的平台，提供可点击链接，尽量复用 Chrome 已有标签：

> 你好，开始更新达人微信前，请先登录：
> - [蝉妈妈](https://www.chanmama.com/bloggerRank/)
> - [抖音达人广场](https://buyin.jinritemai.com/dashboard/servicehall/daren-square)
>
> 请在 Chrome 中完成登录，告诉我“已登录”，我会检查并接着准备。

用户回复后立即检查；不要只答“收到”就结束。网站未打开时可打开上述业务入口；不要把抖音电商宣传首页或店铺首页当成达人广场登录成功。

# 确需控制授权时

先验证已有固定连接；无可复用连接时才通过既有官方扩展连接入口发起一次有效请求。确认授权页实际出现后说：

> 已打开 Playwright 授权页。请选择蝉妈妈标签，点击 **Allow and select**。完成后告诉我“已允许”，我会确认连接并继续。

优先蝉妈妈，再核达人广场。同一授权连接能访问两站时直接复用，不能强求两个弹窗。授权请求保留有效在途命令，不提前结束命令使页面失效；失败先查具体原因，不反复向用户索权。授权页链接由工具实时生成，不能写死旧链接。

用户回复“已允许”（包括“以允许”等明显同义输入）后立即验证实际连接和页面。若缺达人广场标签，用同一连接打开业务入口并核验，不另发授权。

# 准备就绪后

> ✅ 登录和连接已就绪，接下来开始更新名单并采集本次待处理达人。

仅当本次任务已授权业务更新且有待处理库存时自动接续。若只是体验/登录测试或本次库存已完成，应明确准备就绪和无待处理项，不重复处理成功对象、不擅自建立新批次。
